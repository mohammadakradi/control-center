# Project Planning Notes — index

Durable planning context kept by the pm-agent: product decisions and rationale, constraints,
and recurring stack conventions.

**This file is an index (pm rule 9).** The notes live in `.pm/notes/`. Read this index, then open
**only** the topics your request touches — or `grep -ril '<term>' .pm/notes/`. Never read the
whole journal. `CLAUDE.md` is already in your context — never read it. Budgets: this index 8 KB,
each topic file 30 KB.

| Topic | Covers |
|---|---|
| [decisions](notes/decisions.md) | Product and planning decisions and why, oldest first |
| [constraints](notes/constraints.md) | Stacks present, ownership, rules to respect when planning |

Put a new note in the topic file where it belongs; create a topic (and add its row) if none
fits. Correct or delete a stale note. Check `wc -c .pm/notes.md .pm/notes/*.md` before finishing.
